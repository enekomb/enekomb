## 👋 About me

Junior developer from **Bilbao**, Basque Country. I write systems code in C/C++ and build web apps in TypeScript — because I couldn't pick just one.

Trained at **42 Urduliz** — 1,000+ hours, no teachers, no traditional classes, pure project-based learning. You either figure it out or you go home.

- 🔧 Low-level: memory management, UNIX processes, TCP sockets, pipe hell
- 🌐 Web: full-stack with React, Node, MongoDB + a real client project
- 🐧 Daily driver: Linux. Debug tool of choice: Valgrind. Nemesis: malloc.
- 📖 Peer evaluator at 42 — I learned more teaching than I did coding
